# متن‌یاب (MATNYAAB) — نسخه کاتلین / JavaFX

پورت کامل کلاینت دسکتاپ متن‌یاب از Python/PyQt5 به Kotlin/JavaFX.

## تغییرات معماری نسبت به نسخه پایتون

| بخش | نسخه پایتون | نسخه کاتلین |
|---|---|---|
| موتور جستجو | Whoosh | Apache Lucene 9 (همان طرح فیلدها: name/path/size/time/content با توکن‌ساز عربی مشابه) |
| استخراج متن | tika-server-1.28.jar + JRE مجزا | کتابخانه Apache Tika 2.9 درون‌پردازه (بدون نیاز به سرور جداگانه) |
| UI | PyQt5 | JavaFX 21 (همان رنگ‌ها، چیدمان ۳/۲/۲، نوار عنوان سفارشی آبی #2b579a) |
| سریال/اشتراک | AES-CBC + Base32 | دقیقا همان الگوریتم — سریال‌های قبلی معتبر می‌مانند |

### فهرست‌های قدیمی ووش
فرمت باینری Whoosh مبتنی بر pickle پایتون است و خواندن مطمئن آن در JVM ممکن نیست.
به جای مبدل پرریسک، برنامه در اولین اجرا پوشه‌های فهرست قدیمی را از روی `fileInfo.json`
شناسایی کرده و با تایید کاربر، همان پوشه‌ها را خودکار با Lucene دوباره فهرست می‌کند
(کاربر لازم نیست پوشه‌ها را دوباره انتخاب کند).

### شناسه سیستم
در ویندوز از همان منابع WMI (Win32_Processor + Win32_BIOS + Win32_BaseBoard) و در لینوکس از
machine-id و DMI استفاده می‌شود. توجه: چون خروجی متنی WMI در پایتون (repr دیکشنری) و پاورشل
کاملا یکسان نیست، شناسه تولیدی نسخه جدید با نسخه پایتونی متفاوت خواهد بود و کاربران فعلی
باید سریال جدید دریافت کنند (از پنل مدیریت سایت، با ویرایش شناسه سیستمی کاربر و هدیه اشتراک قابل انجام است).

## ساخت (Build)

نیازمندی‌ها: JDK 17+ و دسترسی اینترنت برای دریافت وابستگی‌ها (Lucene, Tika, JavaFX).

```bash
# اگر gradle نصب نیست: sdk install gradle 8.7  یا  از توزیع gradle wrapper استفاده کنید
gradle -p . :app:shadowJar
# خروجی: app/build/libs/app-all.jar
java -jar app/build/libs/app-all.jar
```

برای ساخت خروجی ویندوز (exe) می‌توانید از `jpackage` استفاده کنید:
```bash
jpackage --input app/build/libs --main-jar app-all.jar --name MATNYAAB --type exe --win-menu --win-shortcut --icon app/src/main/resources/image/matnyaab.ico
```

### نکته مهم
این پروژه در محیط توسعه آفلاین تولید شده و امکان کامپایل/اجرا در آن محیط نبوده است؛
در اولین build ممکن است خطاهای جزئی کامپایل ظاهر شود که با اصلاحات کوچک رفع می‌شوند.

## ساختار
```
app/src/main/kotlin/ir/matnyaab/
  Main.kt                    — نقطه ورود + اسپلش + بارگذاری فونت
  core/                      — منطق برنامه (Lucene, Tika, سریال, دانلود, آمار, اخبار, بروزرسانی)
  ui/                        — تمام پنجره‌ها و دیالوگ‌ها (JavaFX)
  util/                      — اعداد فارسی، اندازه فایل، تاریخ جلالی
```


## یادداشت مهاجرت
- فایل‌های IDE، کش Gradle و خروجی‌های build عمداً از ریپو حذف شده‌اند.
- فونت‌های باینری داخل آرشیو اولیه در ریپو نگهداری نمی‌شوند؛ UI از فونت‌های سیستم استفاده می‌کند.
- رمز قدیمی endpoint محتوا از سورس حذف شده و client از مقدار سازگاری غیرمحرمانه استفاده می‌کند.
